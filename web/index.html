Empreinte TLS (usurpation ClientHello)

Le WAF ESA Alibaba Cloud en amont vérifie l'empreinte TLS ClientHello (JA3). Le client desktop ZCode est Electron/Chromium, l'usurpation Chrome par défaut est identique ; en cas de contrôle, essayez firefox/aléatoire.

Informations

· L'empreinte s'applique à la poignée de main TLS de toutes les requêtes amont (quota/activités/relais).

· JA3 personnalisé en 5 segments : version, suites, extensions, courbes, formats ; les extensions inconnues sont ignorées.

· HTTP/2 désactivé (le WAF ESA ne prend pas en charge ALPN h2), conforme au client desktop observé.

Captcha (Alibaba Cloud invisible)

Informations

· Le canal gratuit zcode.z.ai exige X-Aliyun-Captcha-Verify-Param, résolu par Chrome/Edge headless local (le Chromium intégré est détecté).

· Paramètre en cache 45 s, réutilisé avec actualisation en arrière-plan pendant 5 min de tolérance.

· Les IP de datacenter sont contrôlées (risque F001), configurez un proxy résidentiel dans « Proxy de sortie ».

· En mode auto, 2 échecs consécutifs ouvrent un navigateur visible pour validation manuelle, mise en cache identique.

Points d'accès 2API

Auth : Authorization: Bearer sk-xxx ou x-api-key: sk-xxx (générée dans « Paramètres → Sécurité du compte »)

Point d'accèsProtocoleDescription
POST /v1/messagesAnthropic MessagesProtocole natif, streaming SSE pris en charge
POST /v1/chat/completionsOpenAI ChatConverti en requête amont Anthropic, tools / streaming / include_usage pris en charge
POST /v1/responsesOpenAI ResponsesCompatible Codex / SDK OpenAI récents, flux function_call inclus
GET /v1/modelsGénéralListe des modèles (champs OpenAI + Anthropic)

En-tête optionnelle : x-zcode-group: nom_groupe limite aux comptes d'un groupe.

Noms de modèles insensibles à la casse (glm-5.3 → GLM-5.3), préfixe bigmodel/ routé vers le canal BigModel.

Exemple curl

curl http://127.0.0.1:8687/v1/chat/completions \
  -H "Authorization: Bearer sk-votre-CLE" \
  -H "Content-Type: application/json" \
  -d '{"model":"GLM-4.5-Flash","messages":[{"role":"user","content":"Bonjour"}],"stream":true}'
